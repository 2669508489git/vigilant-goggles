# 视频下载

此目录的 MP4 为已完成的原始渲染文件，交付时没有重新渲染或转码。

- 视频：`plastic-product-60s.mp4`，60 秒，900×1200，30fps，1800 帧，H.264，无音轨。
- 可修改源码：`remotion-react-typescript-source.zip`。
- 完整性校验：`SHA256SUMS`。

## 在浏览器中下载

1. 在本目录点击 `plastic-product-60s.mp4`。
2. 在文件页面右上角点击下载箭头，提示文字通常为 **Download raw file**。如果页面显示 **View raw**，也可点击它打开原始视频。
3. 如果浏览器打开视频播放器，右键视频选择“视频另存为”，或在播放器的三点菜单中选择“下载”。
4. 下载源码时点击 ZIP 文件，再点击 **Download raw file**。

若仓库为私有仓库，请先登录拥有该仓库访问权限的 GitHub 账号。
